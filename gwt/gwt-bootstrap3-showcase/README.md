# Bootstrap 3 showcase sources

These are the original [GwtBootstrap3 demo](https://github.com/gwtbootstrap3/gwtbootstrap3-demo)
views adapted for the shared showcase. They demonstrate Bootstrap 3 widgets
and extras with the same Java examples used by the TeaVM track.

- [Run the GWT showcase](https://instanto-io.github.io/bootstrap-widgets/)
- [Run the TeaVM showcase](https://instanto-io.github.io/bootstrap-widgets/teavm.html)
- [Browse the widget guide](../../README.md)
