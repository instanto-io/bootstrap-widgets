# Shared GWT API tests

This module and `../gwt-bootstrap-widget-tests` exercise
[shared GWT API tests](https://github.com/instanto-io/teavm-compat/tree/main/gwt-api).
The Java package is `io.instanto.gwt.testing.api`; the native GWT module is
`io.instanto.gwt.testing.api.GwtApi`.

The same portable tests are also used by Material Widgets. They are test-only
and do not change widget runtime APIs.
